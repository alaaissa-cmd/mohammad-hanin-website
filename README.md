# موقع محمد سلوم

## التشغيل محلياً
1. ثبّت Python.
2. افتح المجلد في VS Code.
3. افتح Terminal ونفّذ:
   pip install -r requirements.txt
4. شغّل:
   python app.py
5. افتح المتصفح على:
   http://127.0.0.1:5000

ملاحظة: GitHub Pages لا يشغّل Flask/Python مباشرة. لاستضافة نسخة Flask استخدم خدمة تدعم Python مثل Render.
